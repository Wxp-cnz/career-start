## 环节 1｜调试训练（45 分钟）

文件已备好：`practice/debug-drill.py`，里面埋了 3 个错误。文件开头的注释写了正确的最终输出。

**做三遍循环**：运行 → 看报错 → 改一处 → 运行。

读 traceback 的固定套路（背下来，以后每次报错都这么看）：

1. **看最后一行**：错误类型 + 一句话结论。`NameError` / `TypeError` / `IndexError` / `KeyError` 是最常见的四个。
2. **往上找最近的 `File "...py", line N`**：这才是你自己代码的位置。上面那些 `site-packages` 的都不用看。
3. **看那一行的变量**：是 `None`？类型不对？下标超了？

然后加一次断点调试。在 `average` 函数的 `for` 循环里插一行 `breakpoint()`（注意缩进要在循环体内），重新运行：

```
(Pdb) p total     # 打印当前 total
(Pdb) p s         # 打印当前这一个元素
(Pdb) n           # 走到下一行
(Pdb) c           # 继续跑完
```

`p` = print，`n` = next，`c` = continue。这三个够用了。

**验收**：三个错误都修好了，输出和文件开头注释里的 5 行完全一致；你能说出每个错误是「哪一行的哪个变量」出了问题。这是本周验收标准之一。

```python
def is_palindrome(s):
    """判断字符串 s 是否回文。是返回 True，否返回 False。"""
    pass


print(is_palindrome("level"))   # True
print(is_palindrome("hello"))   # False
print(is_palindrome("abba"))    # True
print(is_palindrome("a"))       # True
```

提示：`s[::-1]` 是把字符串倒过来的写法，那「正着」和「倒着」相等意味着什么？

**版本 B（双指针，40 分钟）**

同一个文件里另起 `is_palindrome_two_pointers(s)`，禁用切片。左右各站一个人往中间走：

```
left=0 指最左，right=len(s)-1 指最右
只要 left < right：
    s[left] != s[right] → 立刻 return False
    否则 left += 1，right -= 1
循环走完 → return True
```

跑一遍字符串 `"level"`，在纸上（或脑子里）走一遍五个字母，确认每一步 `left`/`right` 指到哪。这一步别省，它是第 26 题「双指针」的模板。

**验收**：两个函数对四个输入的输出完全一致，都是 `True False True True`。

## 环节 3｜练习 5 字母频率（40 分钟）

新建 `practice/05-char-count.py`。

```python
def char_count(s):
    """返回字典：键是字符，值是该字符出现的次数。"""
    pass


print(char_count("hello"))      # {'h': 1, 'e': 1, 'l': 2, 'o': 1}
print(char_count("aab"))        # {'a': 2, 'b': 1}
print(char_count(""))           # {}
```

提示（这是要背下来的惯用法）：

```python
d.get(k, 0)     # 取 d[k]，如果 k 不存在就返回 0，不会报 KeyError
```

于是「计数」就变成一句：`d[c] = d.get(c, 0) + 1`。

**为什么练这个**：两数之和的哈希表解法就是同一个动作——拿一个字典/集合记录「我见过什么」，然后每次查询是 O(1)，不用再扫一遍。

## 环节 4｜练习 6 质数筛选（35 分钟）

新建 `practice/06-primes.py`。

```python
def primes(n):
    """返回 1 到 n 之间（含 n）所有质数组成的列表。"""
    pass


print(primes(20))   # [2, 3, 5, 7, 11, 13, 17, 19]
print(primes(1))    # []
print(primes(2))    # [2]
```

思路：外层 `for i in range(2, n + 1)` 逐个试；内层 `for j in range(2, i)` 看有没有能整除 `i` 的数，一旦找到就 `break` 并标记「不是质数」。

**卡住时想两件事**：
- `i % j == 0` 意味着 `i` 能被 `j` 整除，即 `i` 不是质数。
- 「是不是质数」这个判断结果要存在一个变量里（习惯叫 `is_prime`），循环结束后再看它决定要不要 `append`。这个变量必须在**每次外层循环开始时**重置。

**验收**：三个输出依次是 `[2, 3, 5, 7, 11, 13, 17, 19]`、`[]`、`[2]`。
